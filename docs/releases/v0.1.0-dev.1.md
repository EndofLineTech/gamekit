# Gamekit v0.1.0-dev.1 — development preview

Download **Gamekit-v0.1.0-dev.1.dmg** below. On an Apple-silicon Mac running
**macOS 27**, open the disk image and drag **Gamekit.app** to **Applications**.
The app is prebuilt; Xcode is not required for this preview.

**First launch:** This preview is ad-hoc signed and **not notarized**. A
downloaded copy may be blocked by macOS Gatekeeper even after dragging it to
Applications. If you choose to trust this development preview, use the
per-app **Open Anyway** control in System Settings → Privacy & Security. Do not
disable Gatekeeper system-wide or strip quarantine. This is not the final
Developer ID-signed release.

**Runtime:** The Windows Wine runtime and Apple D3DMetal payload are not in
the DMG. They must be obtained and validated separately by the user. Follow
the bundled `Documentation/USER-GUIDE.md` for the supported setup and scope;
the app targets macOS 27 on Apple silicon only. The DMG also contains the
AGPL license, third-party notices and the source patch/build instructions for
the included Wine-derived module. GitHub provides the Gamekit source archive
for this tag.

This preview includes the native library and managed Windows Steam/Ubisoft
Connect controls from `dev`, including installed Ubisoft game discovery and
verified Store cover artwork. **Known limits:** the Ubisoft Connect CEF GPU
helper can use about one CPU core while the client is idle (`gamekit-lcw`);
Gamekit's Play request for The Division is not a verified gameplay result
(`gamekit-5so.4`). Public notarization, clean-machine first-run and signed
external-runtime acceptance remain under `gamekit-lon`.

The companion JSON manifest identifies the exact source commit, app build,
DMG SHA-256 and ad-hoc signing status. Verify its hash against the downloaded
DMG before using the preview.
